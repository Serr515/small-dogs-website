# Сайт о маленьких породах собак

Частный рабочий проект сайта для прямой продажи собак небольших пород в Москве и Московской области, Россия. Проект только начинается: бренд, сведения о продавце, объявления и ассортимент ещё не согласованы.

## Состояние

Это подготовительный сайт, а не работающий интернет-магазин. Настоящих объявлений, фотографий конкретных собак на продажу, цен, оформления заказа и оплаты здесь пока нет. Для связи указан Telegram @sergey_09855. Карточки пород используют иллюстративные фотографии с открытыми лицензиями.

## Предварительная идея

- Информация о небольших породах и особенностях ухода.
- Каталог собак с проверенными данными и фотографиями — после предоставления владельцем.
- Страницы с информацией о продавце и условиях приобретения.
- Способ связи и заявка после выбора подходящего варианта.
- Адаптация для телефона и компьютера.

Животные должны содержаться и передаваться ответственным образом; сведения о происхождении, здоровье, возрасте и условиях передачи необходимо проверять по каждому конкретному животному. Правила продажи и требования к обработке личных данных зависят от страны работы и должны быть проверены перед запуском.
